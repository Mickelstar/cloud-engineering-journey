# Day 10 — Docker Containerization

## 1. Objective

Learnt the fundamentals of Docker by:

- Installing Docker Desktop
- Configuring Windows virtualization and WSL
- Creating a simple web application

- Mapping container ports to the host
- Testing the application
- Inspecting the running container
- Understanding the relationship between Dockerfiles, images, and containers
